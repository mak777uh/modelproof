ModelProof

Permanent, verifiable AI models on Arweave. Paste a manifest transaction id: your browser downloads the weights from the permaweb, checks their SHA-256, and re-runs every recorded inference with integer-only math. If one bit differs, verification fails.







 Run the verified model yourself (Iris flower, measurements in cm)
 

  
  
 

 sepal length · sepal width · petal length · petal width

 
 






 How it works: weights are stored as an int8 MPW1 file; inference uses only integer add/multiply, ReLU and an arithmetic right-shift, so Python, Node and every browser produce byte-identical outputs. The manifest pins the weights' hash, the Arweave TX of the weights, test vectors and a digest of all outputs.
